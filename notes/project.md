The goals of this project are to develop marimo notebooks using syntactic analyses generated by `arsgrammatica` (https://github.com/neelsmith/arsgrammatica). The `data` directory has plain-text files with analyses in the format described in https://neelsmith.github.io/arsgrammatica/reference/analysisformat.html.

The first marimo notebook should 1) automatically load all the analysis files and 2) create a marimo notebook in the `marimo` directory that mimics the functionality of `arsgrammatica`'s `latin_syntaxer_review.py` notebook (https://github.com/neelsmith/arsgrammatica/blob/main/marimo/latin_syntaxer_review.py), but instead of letting the user browse for data sources, loading the files in `data` without any user prompting or intervention.
